# 第一次同步

准备两台能连到同一网络的设备。下面用一台电脑和一部 Android 手机演示：电脑运行内置服务器，手机连接这台电脑。已有 WebDAV 或 S3 的用户可以直接[连接现有存储](./storage)。

## 1. 在电脑上启动服务器

安装并打开[桌面客户端](./desktop)，进入 **服务器**，设置用户名、密码和端口，打开服务器开关。默认端口是 `5033`。记下电脑的局域网 IP，例如 `192.168.1.20`。

## 2. 让电脑也参与同步

打开 **剪贴板同步 → 同步账号 → 添加账号**，选择 SyncClipboard 服务器。地址填写 `http://127.0.0.1:5033`，输入刚设置的用户名和密码。选中该账号，开启剪贴板同步。

## 3. 从手机连接电脑

安装 [Android 客户端](./android)，在 **设置 → 服务器配置** 中添加 SyncClipboard 服务器。输入电脑的局域网地址（例如 `http://192.168.1.20:5033`）和同一组账号密码，点击 **测试连接**，保存并选用该服务器。在手机上填写 `127.0.0.1` 会连接手机自己。

## 4. 试一次双向同步

在电脑上复制一段容易辨认的文字，例如 `电脑发给手机 123`。打开手机端首页，在「远程剪贴板」找到这段文字并复制，切到记事应用粘贴。再在手机上复制另一段文字，打开 SyncClipboard 上传本地剪贴板，然后在电脑上粘贴。

如果手机连接超时，检查 Wi-Fi 是否能访问电脑、端口是否与设置一致，以及电脑防火墙是否允许局域网访问该端口。如果连接成功但内容没有变化，先确认两端选中了同一个服务器，再检查电脑端的同步开关。
