# SyncClipboard

<IntroHistory alt="Windows、Linux 和 macOS 上的 SyncClipboard 历史记录面板。" />

SyncClipboard 是一款跨设备剪贴板同步工具。在一台设备上复制文本、图片或文件，就可以在连接到同一服务器的另一台设备上粘贴。

客户端支持 Windows、macOS、Linux 和 Android，可以在后台自动同步剪贴板。iPhone 和 iPad 可以通过快捷指令手动或半自动上传或下载剪贴板内容。

在历史记录中，可以按文字或文件名查找之前复制的内容，收藏常用记录，或用标签整理记录。使用 SyncClipboard 官方服务器时，还可以在多台设备之间同步历史记录。

SyncClipboard 还提供针对本机剪贴板的功能优化，包括在应用和文件夹之间复制粘贴图片、复制网页图片时下载原图，以及针对 HEIC、WebP 等图片格式的兼容性优化。
