# SyncClipboard

<IntroHistory alt="SyncClipboard history panels on Windows, Linux, and macOS." />

SyncClipboard syncs clipboard contents across devices. Copy text, an image, or a file on one device and paste it on another connected to the same server.

On Windows, macOS, Linux, and Android, the client can automatically sync the clipboard in the background. On iPhone and iPad, shortcuts support manual or semi-automatic uploads and downloads of clipboard contents.

Clipboard history can be searched by text or file name. Frequently used items can be saved as favorites, and tags help organize records. The official SyncClipboard server also supports syncing history across devices.

SyncClipboard also enhances the local clipboard by supporting image copy and paste between apps and folders, downloading original images when copying from web pages, and improving compatibility with image formats such as HEIC and WebP.

For instructions on choosing a server and setting up clients, see [Start syncing](./getting-started).
