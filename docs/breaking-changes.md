# 不兼容变更记录

## v3.3.4

Intel Mac 的最低系统要求从 macOS 12.7 提高到 13.3。Apple 芯片机型仍支持 macOS 12.7。

## v3.3.0

- Linux 客户端和服务端的 glibc 最低版本提高到 2.38。从 v3.3.3 起，AppImage 自带 glibc，可以在较旧的系统上运行。
- 独立服务端和不带运行时的客户端升级到 .NET 10。使用这些版本时，需要同时升级系统上的 .NET 运行时。

## v3.1.3

客户端移除了信任不安全 HTTPS 证书的选项。使用私有证书颁发机构时，请将其根证书加入操作系统的信任列表。

## v3.1.1

同步协议发生变更。从更早版本升级时，同一同步网络中的客户端和独立服务端需要一起升级，第三方客户端也需要支持新协议。使用移动端第三方工具的设备需要重新导入配置。[相关说明 #286](https://github.com/Jeric-X/SyncClipboard/issues/286)

桌面客户端的本地历史记录格式也已变更。首次运行新版前，请先备份应用数据目录中的 `data` 和 `file` 文件夹，再将它们移出应用数据目录。旧历史记录不会自动迁移。[各系统的应用数据目录](./desktop/#卸载)
